Lastmod API reference

The read-only API of Lastmod (/v1). A field may be added; renaming, removing or changing the type of a field only happens in a new version. Timestamps are ISO 8601 in UTC, days are YYYY-MM-DD.

The API is served from https://api.lastmod.ai/v1. Send an API key as a bearer token. The same description is available as OpenAPI JSON.

Endpoints

List websites

GET /v1/websites

The websites within the scope of the key.

List opportunities

GET /v1/websites/{websiteId}/opportunities

The opportunities of a website, with a filter on status and type.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.
  • status (query, string (OPEN, DISMISSED, CONVERTED, RESOLVED, VOIDED, ALL), optional): Only opportunities with this status. Without this parameter RESOLVED and VOIDED are omitted; ALL returns every status in one list.
  • type (query, string, optional): Only opportunities of this type, as it appears in the list.
  • limit (query, integer, optional): Number of opportunities per page, at most 200 (also the default). meta.truncated is true if there are more; then follow meta.nextCursor.
  • cursor (query, string, optional): meta.nextCursor of the previous page. Sorted by lastSeenAt descending, then id.

Get an opportunity

GET /v1/websites/{websiteId}/opportunities/{opportunityId}

A single opportunity, with resolution, task and evidence. For a site-wide opportunity the evidence holds at most 100 page rows; the summary row names pagesAffected (all pages involved) and truncated.

Parameters

  • websiteId (path, string, required)
  • opportunityId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.

List tasks

GET /v1/websites/{websiteId}/tasks

The tasks of a website.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.
  • status (query, string (TODO, IN_PROGRESS, DONE, CANCELLED), optional): Only tasks with this status.
  • limit (query, integer, optional): Number of tasks per page, at most 200 (also the default). meta.truncated is true if there are more; then follow meta.nextCursor.
  • cursor (query, string, optional): meta.nextCursor of the previous page. Sorted by id descending (newest first).

List results

GET /v1/websites/{websiteId}/results

The measured results of completed changes, most recent first, with a cursor.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.
  • cursor (query, string, optional): meta.nextCursor of the previous page.
  • limit (query, integer, optional): Number of results per page.
  • band (query, list of string (HIGH, MEDIUM, LOW, INCONCLUSIVE), optional): Only results with this reliability; repeat the parameter for more bands.
  • mixed (query, boolean, optional): true: only results with a mixed picture; false: only results without.
  • from (query, string, optional): Only results calculated from this moment, ISO 8601.
  • to (query, string, optional): Only results calculated up to this moment, ISO 8601.

Get KPIs

GET /v1/websites/{websiteId}/kpis

The KPIs of a website over a period.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.
  • periodStart (query, string, required): Start of the period (inclusive), ISO 8601.
  • periodEnd (query, string, required): End of the period (exclusive), ISO 8601, after periodStart and within the maximum window.

Get search performance

GET /v1/websites/{websiteId}/timeseries

Search performance per day or per week, with markers for changes and events.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.
  • periodStart (query, string, required): Start of the period (inclusive), ISO 8601. With a time zone.
  • periodEnd (query, string, required): End of the period (exclusive), ISO 8601, after periodStart and within the maximum window. With a time zone.
  • granularity (query, string (auto, day, week), required): day, week, or auto (the API chooses; the response says which).

Get AI visibility

GET /v1/websites/{websiteId}/visibility

AI visibility per engine over a recent window, with an uncertainty band and the previous measurement as a separate observation.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.

List measurement rounds

GET /v1/websites/{websiteId}/visibility/rounds

The completed measurement rounds, oldest first, without a difference or trend.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.

List prompts

GET /v1/websites/{websiteId}/visibility/prompts

The tracked and suggested questions with the plan limit. Read-only.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.

List themes

GET /v1/websites/{websiteId}/visibility/themes

Topics with answer counts per engine, and the opportunity and task that followed from the scan.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.

Get AI referrals

GET /v1/websites/{websiteId}/ai-referrals

Sessions in Google Analytics that come from AI assistants, as context. Covered days only.

Parameters

  • websiteId (path, string, required)
  • locale (query, string (en, nl), optional): The language of the texts (reason, recommendedAction, task titles). Defaults to en.
  • days (query, integer (7, 28, 90), optional): The period in days: 7, 28 (default) or 90.

Responses

  • 200 Success.
  • 400 An invalid or unknown query parameter.
  • 401 Missing, invalid or expired key. The response carries WWW-Authenticate: Bearer.
  • 404 The website or object does not exist, or falls outside the scope of the key (deliberately the same response).
  • 429 Too many requests. Retry-After says after how many seconds you can retry.
