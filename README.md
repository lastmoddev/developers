# Lastmod developer documentation

Documentation of the **Lastmod API** and the **Lastmod MCP server**, published at **<https://developers.lastmod.ai>**.

Lastmod ([lastmod.ai](https://www.lastmod.ai)) is the proof layer for SEO and AI visibility: it finds what your website should change, looks for the change on the live page, and measures what changed afterwards.

## Start here

| | |
| --- | --- |
| [API reference](https://developers.lastmod.ai/api/) | Every `/v1` endpoint, with parameters, responses and errors |
| [MCP server](https://developers.lastmod.ai/mcp/) | Read-only tools for AI assistants such as Claude or ChatGPT |
| [OpenAPI description](https://developers.lastmod.ai/spec/v1.openapi.json) | The same description as JSON, for your own tooling or to generate a client |
| [Connect an AI assistant](https://www.lastmod.ai/en/connect-ai-assistant) | Step-by-step guide for end users |

The API is read-only and served from `https://api.lastmod.ai/v1`. You create an API key in the settings of your organisation at [lastmod.ai](https://www.lastmod.ai).
